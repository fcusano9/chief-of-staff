# Design mockups

Every visual change is approved as a clickable mockup before it's built (see AGENTS.md). Open any file in a browser; the notes box explains the choices.

Mockups are a record of what was approved at the time and aren't updated afterwards, so many show screens that have changed since. The app and [docs/BUSINESS-RULES.md](../docs/BUSINESS-RULES.md) are the source of truth; the reasons are in [docs/DECISIONS.md](../docs/DECISIONS.md).

**Status:** Current means the app still looks broadly like this. Partly means some of it was replaced later. Replaced means a later mockup took its place.
