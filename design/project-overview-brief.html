Mockup notes (not part of the app)

  • Overview is one sentence on what the project is (two at most), in a softer color right under the name, and under each name in the list. You write it yourself: click the pencil (or the empty line) to edit, Ctrl+Enter saves, Esc cancels. The AI doesn't write it. The project name is a little bigger so the two don't look alike.
  • Project brief is now a short, high-level status: where the project stands, recent decisions, what's next and what's open. The AI writes it from the full history, the project's open tasks and the standing instructions.
  • The brief works like the People brief: Regenerate shows a suggestion with Keep, Discard and Try again, Edit lets you write it yourself, and nothing is saved until you keep it. A tag shows how many history notes arrived since it was written. Try Dealer training.
  • History holds every dated note from imports (each accepted "Project context" suggestion in Review) plus anything you add. It's no longer on the page: the History button opens it, newest first, with new notes marked. You can add a note or edit it there.
  • Existing projects: what's in today's brief box moves into History unchanged. The overview starts empty until you write one, and the brief until you click Write brief. Try Partner portal refresh.
  • What the AI reads on each import: each project's name, overview, brief and standing instructions. When a project has no brief yet, it reads the newest history notes instead. Today it reads the first 400 characters of the brief box, which are the oldest notes.
